# 📄 Document Analysis Platform

Upload documents (PDF), extract their content with your choice of engine, and ask questions
about them in natural language. Answers are generated by **Claude (Anthropic)** with an
automatic **OpenAI fallback**, grounded in the document via RAG over **PostgreSQL + pgvector**,
and every answer cites the page it came from.

- **Frontend** — Next.js 14 (App Router, TypeScript, Tailwind)
- **Backend** — FastAPI (Python 3.11), SQLAlchemy 2.0, Alembic
- **LLM** — Anthropic Claude (primary) → OpenAI (fallback) behind one provider interface
- **Embeddings** — local `fastembed` (ONNX, CPU) — no embedding API key required
- **Storage** — PostgreSQL + `pgvector` (documents, text chunks, embeddings, query logs)
- **Extraction** — three user-selectable methods: **Text** (PyMuPDF), **OCR** (YOLOv8 layout +
  Tesseract + poppler), **Vision** (page images sent to the LLM)
- **Auth** — JWT (access + refresh) plus optional API-key access
- **Observability** — detailed structured logging with per-request correlation ids

## Quick start

### Option A — Docker (everything in one command)

Prerequisites: Docker Desktop.

```bash
cp .env.example .env          # then edit .env and set ANTHROPIC_API_KEY
docker compose up --build
```

- Frontend → http://localhost:3000
- Backend API docs → http://localhost:8000/docs

The backend image bundles Tesseract + poppler, so the OCR and Vision methods work with no
host installs. Migrations run automatically on startup.

### Option B — Local development

Prerequisites: Python 3.11, Node 20, and a PostgreSQL 16 + pgvector instance
(easiest: `docker compose up -d postgres`).

**Backend**

```bash
cd backend
python -m venv .venv && . .venv/Scripts/activate    # Windows
#   source .venv/bin/activate                        # macOS/Linux
pip install -r requirements-dev.txt
cp .env.example .env          # set ANTHROPIC_API_KEY, DATABASE_URL, JWT_SECRET
alembic upgrade head          # create tables + pgvector extension + HNSW index
uvicorn app.main:app --reload
```

**Frontend**

```bash
cd frontend
npm install
cp .env.local.example .env.local      # NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev
```

> **Windows note (OCR only):** the `ocr` method needs Tesseract and poppler installed and on
> `PATH` (or set `TESSERACT_CMD` / `POPPLER_PATH` in `backend/.env`). The **Text** and
> **Vision** methods need neither. Docker handles all of this for you.

## How it works

```
Upload PDF ──► choose method (Text | OCR | Vision)
                     │
                     ▼
         Extraction ─► Chunking ─► Embeddings (fastembed)
                     │
                     ▼
         PostgreSQL + pgvector  (chunks + vectors)
                     │
   Ask a question ──►│ embed query → top-k similarity search
                     ▼
         Claude (→ OpenAI fallback) generates a cited answer (streamed)
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for component and sequence diagrams.

## Using it

1. **Sign up / log in** at http://localhost:3000.
2. **Upload** a PDF and pick an extraction method:
   - **Text** — fast, for digital PDFs with selectable text.
   - **OCR** — scanned pages; runs YOLOv8 layout detection then Tesseract per region.
   - **Vision** — sends page images to Claude; best for complex layouts, charts, and scans.
3. Wait for the document status to turn **ready** (the list auto-refreshes).
4. Open **Chat** and ask questions. Answers stream in and cite page numbers; expand
   **Sources** to see the retrieved chunks and which provider answered.

```bash

cd backend && ruff check .    # lint
cd frontend && npm run build  # type-check + production build
```

lint/build on every push and PR — see [.github/workflows/ci.yml](.github/workflows/ci.yml).
